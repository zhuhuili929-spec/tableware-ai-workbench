# 商用餐具 AI 视觉工作台

面向商用餐具的浏览器端 AI 视觉工作台。

## 文件说明

- `index.html`：网站入口，可用浏览器打开。
- `商用餐具AI视觉工作台.html`：原始中文文件名版本，与入口文件内容相同。
- `案例图/`：39 张案例素材，可在工作台中选择上传。

## 使用

打开 `index.html`，在设置中填写 API 地址、模型及自己的 API 密钥。密钥保存在当前浏览器的 localStorage 中，调用 AI 服务时会发送给所配置的 API 服务。仓库不包含已填写的密钥。

部分图片处理和导出功能需要联网加载依赖。实际 AI 调用需要有效 API 服务，并受该服务的浏览器跨域配置限制。
